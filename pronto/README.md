# TecnoLoja — versão pronta

## Abrir o aplicativo

1. Baixe **[TecnoLoja-Windows.zip](TecnoLoja-Windows.zip)** e extraia tudo.
2. Abra **Abrir-Loja.bat** dentro da pasta extraída.
3. Crie sua conta. A primeira conta será administradora.

Requer **Java 17 ou superior**. O banco local é criado automaticamente.

## Código-fonte

O arquivo **[TecnoLoja-Codigo.zip](TecnoLoja-Codigo.zip)** contém o código completo, as verificações e as instruções detalhadas.

Para executar a partir do código, extraia o ZIP e abra **Iniciar.bat**. A compilação requer **JDK 17 ou superior** e internet na primeira execução para baixar os drivers.
